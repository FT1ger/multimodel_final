# CrisisMMD Multimodal Fusion

Five-class humanitarian classification of disaster tweets with text and
image fusion. The project compares frozen-feature baselines, early fusion,
late fusion, and bidirectional cross-attention on the CrisisMMD v2.0
agreed label split.

## Data

The data is subject to the CrisisNLP terms of use: research use only, no
redistribution of content, deletion after the project. Raw tweets and
images are not included in this repository.

Expected local layout:

```text
../data/CrisisMMD/data_image/
data/splits/crisismmd_datasplit_agreed_label/
data/splits/crisismmd_datasplit_all/
```

The splits are the official `crisismmd_datasplit_agreed_label` and
`crisismmd_datasplit_all` archives. The original crisisnlp.qcri.org is
offline; the archived copies used here were retrieved from the Wayback
Machine snapshot dated 2025-07-15 and have SHA-1
`5ff449b5cbbb1cd206902cd4489ad0f394da405d` (agreed) and
`0a3cbab1667b3a7de1c960442298150f63944fba` (all). Place the image folder
from CrisisMMD v2.0 so that
`data/splits/.../task_humanitarian_text_img_agreed_lab_train.tsv` paths
resolve under `../data/CrisisMMD/`.

## Reproduce

From the repository root:

```bash
python src/data.py
python src/features.py --what all
python src/baseline.py --out results_std
python src/train.py --models mlp_image,mlp_text,mlp_early,late,token_late,cross \
  --seeds 0,1,2 --out results_std
python src/train.py --models mlp_image,mlp_early,late --image-key r50 \
  --seeds 0,1,2 --out results_r50_std
python src/evaluate.py --results results_std --models \
  logreg_image,logreg_text,logreg_early,logreg_late,mlp_image,mlp_text,mlp_early,late,token_late,cross
python src/leave_one_event_out.py
python src/neural_loeo.py
python src/dual_head.py
python src/train.py --models mlp_image_deep,mlp_text_deep \
  --seeds 0,1,2 --out results_controls_std
python src/train.py --models mlp_image_deep,mlp_text_deep --image-key r50 \
  --seeds 0,1,2 --out results_controls_r50_std
python src/train.py --models mlp_early --seeds 0,1,2 --shuffle-text \
  --out results_shuffled_std
python src/train.py --models mlp_early --image-key r50 --seeds 0,1,2 \
  --shuffle-text --out results_shuffled_r50_std
python eda/eda_images.py ../data/CrisisMMD data/splits eda
python src/dedup.py
python src/sensitivity.py
python src/calibration.py
python src/efficiency.py
python src/report_metrics.py
python src/figures.py
```

The class weight control (Table A7) and the logistic gaps and error counts
(Table 2, Section 4.2) come from a separate rerun:

```bash
python src/train.py --models mlp_early,late --seeds 0,1,2 \
  --out results_rerun/weighted
python src/train.py --models mlp_early,late --seeds 0,1,2 \
  --no-class-weights --out results_rerun/unweighted
python src/supplement.py
```

`supplement.py` refits the logistic baselines with fixed regularisation
and writes `class_weight_summary.csv`, `logreg_gap.csv`,
`error_modalities.csv` and `error_confidence.csv` to `results/report/`.

`eda_images.py` writes the image audit used by `dedup.py`; `data.py`
already uses the committed `assets/placeholder_ids.csv`, so a fresh clone
does not need the audit to build manifests.

`report_metrics.py` writes the additional aggregate tables used in the
report to `results/report/`.

`features.py --what all` extracts pooled EfficientNet-B0 and BERT features,
ResNet-50 pooled features, and the token-level features used by
cross-attention. Extraction overwrites the corresponding cache; use
`--what pooled`, `--what r50`, `--what tokens`, or `--what text` to
regenerate one family. `--shuffle-text` permutes text features across rows
for the shuffled-pair control; `mlp_image_deep` / `mlp_text_deep` are
capacity-matched single-modality controls.

The pHash pair file used by `dedup.py` is generated by
`prelim/near-duplicate_check.ipynb` (pHash, Hamming distance at most 6).
Run that notebook once after `data.py` if
`cache/near_duplicates_humanitarian.csv` is absent; `dedup.py` then writes
`results/report/dedup_flags.csv` for `sensitivity.py`.

## Results

With train-only standardisation, ResNet-50 early and late fusion reach
macro-F1 0.821 and 0.820; EfficientNet-B0 early fusion 0.812; logistic
late fusion 0.799; B0 late and token-pooled late 0.797 and 0.798; and
cross-attention 0.795. Neural single-modality controls reach 0.711 for B0
image and 0.726 for text; R50 image-only reaches 0.743. Fusion improves
over neural single modalities, but R50 early and late fusion are
indistinguishable on macro-F1. R50 late gains 0.077 over the best single
modality (R50 image), with a 95% bootstrap interval over seeds and test
rows of [0.027, 0.127]. The intervals for R50 early ([0.018, 0.133]) and
B0 early ([0.005, 0.129]) also exclude zero; the logistic late interval
([-0.011, 0.120]) includes zero. Leave-one-event-out is heterogeneous:
mean macro-F1 over the classes present in each event is 0.764 for logistic
early fusion and 0.735 for logistic late fusion (0.699 and 0.667 over all
five labels). The test split was used in the preliminary experiment, so
final test numbers are indicative.

## Hardware

Apple M4 16GB with MPS. The frozen EfficientNet-B0 extraction takes about
145 seconds for 18,082 images; BERT pooled features take about 73 seconds
for 16,058 tweets. Cross-attention training uses the cached token features.

## Compliance

This repository contains code, report sources, aggregate result tables,
and figures. It does not contain `data/`, `cache/`, raw tweets, images,
usernames, or per-sample predictions. The report, slides, and video
contain aggregate statistics only. Local data are not retained after the
project.
